# Vue 3 规范代码生成器

将需求转换为功能点，确认后按照项目规范生成 Vue 3 + TypeScript 代码。

## 功能特点

- 🎯 **需求转功能点** - 将模糊需求转换为清晰的功能点清单
- ✅ **用户确认** - 功能点确认后再开始编码，避免返工
- 📋 **规范生成** - 按照项目规范生成代码
- 🔢 **有序组织** - 代码块分类有序，不随意插入

## 使用方式

1. 描述你的需求
2. 查看生成的功能点清单
3. 确认或修改功能点
4. 获取规范的代码

## 包含的 Steering 文件

- `requirement-to-features.md` - 需求转功能点的详细流程
- `code-organization.md` - 代码块分类和组织规范
- `component-standards.md` - 组件使用规范

## 代码块顺序

生成的代码按以下顺序组织：

1. 导入声明
2. 类型定义
3. 枚举/常量定义
4. Props/Emits 定义
5. 路由/Store 实例
6. 响应式数据
7. 计算属性
8. API 实例化
9. Hooks 实例化
10. 方法定义
11. 监听器
12. 生命周期
13. 暴露方法

## 注意事项

此 Power 不包含 MCP 服务器，纯粹通过 steering 规则指导代码生成。
